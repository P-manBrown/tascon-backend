# todoist-task-runner

Todoistをタスクキューとして、execution-plan単位の実装〜ローカルコミットまでを連続処理する。リモートへの反映（PR作成・マージ）は行わない。

## 対象タスクの取得

- `tascon-backend`ラベルが付いたタスクを`find-tasks`で取得する
- Todoist上のセクション順・タスク順（並び順）に従って処理する
- 「作業する」子タスクが未完了の親タスクのみを対象とする

## 処理フロー

1. 対象タスクをexecution-plan（機能）単位でグルーピングする
2. 各単位ごとに、`Agent`ツールで新規サブエージェントへ委任する。親セッションとは独立したまっさらなコンテキストで処理させることで、機能ごとにコンテキストが独立する（セッション切り替え相当）
3. サブエージェントは以下を行う:
   - `execution-plan` skillでplanを作成・更新する
   - `execution-plan`の自律実行モードに従い、1ステップずつブランチを切りgit-spiceでスタックしながら連続実行する
   - `codex-delegation` skillに従い実装をCodexへ委譲し、成果物を確認してからコミットする
   - 各Stepの「作業する」子タスクを`complete-tasks`で完了させる
4. サブエージェント完了後、親は結果を確認し次の単位へ進む

## 質問が必要な場合

- 判断に迷った場合、まず`add-comments`で該当タスクにコメントを投稿する（人間への非同期通知）
- その後`AskUserQuestion`で選択肢を提示し、応答を待つ

## 終了条件

- 担当タスク（`tascon-backend`ラベル、「作業する」子タスクが未完了）が無くなったら、何もせずセッションを終了する

## 変更範囲

- 変更してよい対象: Todoistタスクの作成・削除・完了処理、`.claude/plans/`、実装コード（サブエージェント経由でCodexへ委譲）、ローカルのコミット・ブランチ
- 変更してはいけない対象: リモートリポジトリへの操作（PR作成・マージ）。人間の明示的な指示があるまで行わない

## 他skillとの責務分離

- `execution-plan`: 個々のplan文書管理を担当。このskillから呼ばれる
- `git-spice-workflow`: コミット・ブランチ・PR操作を担当
- `codex-delegation`: Codexへの実装委譲手順を担当
- `todoist-task-runner`: 上記を束ね、Todoistとの同期・タスクキューの消化を担当

## 未検証事項

- `AskUserQuestion`が長時間実行中のセッション・サブエージェント内でどう振る舞うか
- `Agent`ツールで起動したサブエージェントが、親と同じ権限（Codex委譲、git操作等）を引き継げるか

初回実行時に実際の挙動を確認し、問題があれば設計を見直すこと。
