# todoist-task-conventions

Todoistで新規タスクを作成する際の共通ルール。個々のワークフローskill（`todoist-task-runner`、`tech-debt-tracker`等）は、タスク作成時にここを参照する。

## ラベル

- `tascon-backend`: リポジトリ判別用。親タスク（親を持たない単発タスクはそのタスク自体）に付与する
- `Claude Code`: AIが処理することを許可された明示的opt-in。**実際にAIが処理する単位**（機能実装タスクなら「作業する」子タスク、親を持たない単発タスクはそのタスク自体）に付与する。`Claude`という別ラベルはこれとは別物

## 子タスク構成

- 親タスクに「作業する」「最終確認する」「プルリクエストする」の3つを必ず付与する。`Claude Code`ラベルは「作業する」にのみ付ける

## 指示・進捗の記載場所

- Claude Codeへの指示（description）は、実処理単位（機能実装タスクなら「作業する」子タスク、親を持たない単発タスクはそのタスク自体）に記載する
- 進捗コメント（`add-comments`）は、親タスク（親を持たない単発タスクはそのタスク自体）に記載する
